
# Jogo de Adivinhação de Palavras

Projeto desenvolvido na disciplina de Desenvolvimento de Aplicações Web I, do IFPB.

## Integrante
- Maria Heloísa Alves Caetano

## Como jogar
Digite uma letra e clique em Tentar. O objetivo é descobrir a palavra antes de acabar as tentativas.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript

## Funcionalidades
- Escolha aleatória de palavras.
- Revelação das letras corretas.
- Controle de tentativas.
- Identificação de letras utilizadas.
- Bloqueio de letras repetidas.
- Mensagem de vitória ou derrota.
- Botão para iniciar uma nova partida.
